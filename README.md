# FusnChain Official Website

**Live at:** https://fusnchain.github.io/FusnChain/

Built with pure HTML/CSS/JS - no build step required.

## Features
- 🌐 Bilingual (Chinese/English)
- 📱 Fully responsive
- ⚡ Fast loading with CDN
- 🎨 Modern UI with animations
- 🔗 Expandable ecosystem & partners sections

## Adding Content

### Add Ecosystem Projects
Edit `assets/js/main.js` → `ecosystemProjects` array

### Add Partners
Edit `assets/js/main.js` → `partners` array

## Tech Stack
- Tailwind CSS
- Alpine.js
- AOS (scroll animations)
- Chart.js
- Particles.js
