# Tokenomics & Ecosystem FAQ

## FSN Token Basics

### What is FSN?

FSN is the native token of the FusnChain blockchain. It serves multiple purposes:

- **Gas Fees**: Pay for transaction and smart contract execution
- **Staking**: Validators stake FSN to secure the network
- **Governance**: Participate in protocol governance decisions
- **Value Transfer**: Transfer value across the FusnChain network
